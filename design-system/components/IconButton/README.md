# IconButton

A 32 × 32 label-less button with one icon: row actions (edit, change password), the header bell, dialog close, show password.

- Provide: `icon`, `label` (screen readers; also the tooltip unless `tooltip` is set or `false`), `danger` (red hover for delete), `on` (current, `primary-soft`), `disabled`.
- Icon `text-muted`; hover `surface-alt` with `text`. Tooltips are `tooltip` ground, caption text, `radius-sm`.
