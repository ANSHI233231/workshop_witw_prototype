# FormSection

A white form section with a heading, for long website forms.

- **You supply** `title` and the fields (FormField in `pk-g2` / `pk-g3` grids, ImagePicker). Put sections in a `pk-form` column (880px) and end with a `pk-foot` row of buttons.
- Source: PK-W1 Become a Partner ("Your account", "Your business"), PK-P2.
