# SafariSummary

The top of a shared safari's page: the photo, the uppercase title, dates, park and organiser, a grid of six facts, the share buttons and the main action.

- **You supply** `image`, `title`, `dates`, `park`, `organiser`, `facts` (icon key, label, value — trip, seats, safaris, stay, theme, cost) and `actions` (Join Safari, or Leave / Edit for members and the host). `badge` adds a status next to the title.
- Dates are italic `event-green` (WITW's colour, 3.4:1 at 20px — flagged); fact icons are `accent-2`.
- The share circles use each network's own colour (Facebook, X, Instagram, WhatsApp, LinkedIn, Telegram, Copy link) with a white icon.
- It sits in the page's padding and stretches to its edges; put it first inside the page.
- Source: W3 Shared Safari view.
