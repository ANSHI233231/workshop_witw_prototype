# JoinedLeft

How many people joined and left a safari, each number a link to that list.

- **You supply** `joined`, `left`, and `onJoined` / `onLeft` to open the Joined / Left list.
- Text buttons in `primary`, separated by "/"; centred in the table's "Joined / left" column.
- Source: C1 Shared Safaris list, C2 Joined / Left list.
