# PriceBar

The price strip under the package summary: price per person, struck-out price, total, message and Request a quote.

- Provide: `price`, `total`; optional `before`, `message`, `partner` and `partnerHref` ("Operated by" with the business name as a ProfileLink to the Partner Profile), `left` (your own left side instead), `saved` / `onWish` (the inline WishlistButton before the button), `action` or `actionLabel` and `onAction`.
- Sticks to the bottom of the screen on phones.
