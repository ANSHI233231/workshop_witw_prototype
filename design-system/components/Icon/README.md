# Icon

Lucide line icons, exactly as the app draws them: 24px grid, stroke 2, round caps, `currentColor`.

- Provide: `name` (`search`, `pencil`, `key-round`, `bell`, `plus`, `file-down`, `rotate-ccw`, `x`, `menu`, `chevron-down`, `chevron-right`, `chevron-left`, `layout-dashboard`, `users`, `settings`, `shield-check`, `lock`, `log-out`, `eye`, `triangle-alert`, `check`, `check-check`, `save`, `arrow-left`, `clock`, `mail`) and `size` (`sm` 16 · `md` 18 · `lg` 20).
- `icon-sm` in buttons, inputs and tables; `icon-md` in the sidebar and wordmark mark; `icon-lg` in the header.
