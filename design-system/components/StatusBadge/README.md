# StatusBadge

A small status label with a coloured dot: "Active", "Inactive", "Draft", "Failed".

- Provide: `tone` (`success` | `warning` | `info` | `danger` | `neutral`) and the word.
- Height `badge-height`, `radius-full`, style `badge`; colours `badge-<tone>-text`, `-bg`, `-dot`. Centre it in a Status column.
