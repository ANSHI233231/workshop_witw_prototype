# ConversationItem

A conversation in the Messages list: initials or picture, name, date and time, the start of the last message and the unread count.

- Provide: `name`, `preview`, `time` ("03 Nov 2026 08:20", IST); optional `photo`, `initials`, `unread`, `active`, `onOpen`.
- The preview is cut at 50 characters and ends with " …". Unread: the preview turns bold `text`. Open: `primary-soft` with a 3px `primary` bar on the left.
- Source: U5 Messages.
