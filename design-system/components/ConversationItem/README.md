# ConversationItem

A conversation in the Messages list: the other user's picture and name, the start of the last message and its date and time.

- Provide: `name`, `preview`, `time`; optional `photo`, `initials`, `unread`, `active`, `onOpen`.
- The preview is cut at 50 characters and ends with "…". Unread conversations are bold with the count. Dates in IST, "23 Nov 2026, 10:42 AM".
