# Toggle

A small 28 × 16 switch, used in a table's Actions column to activate or deactivate a row.

- Provide: `checked`, `label` (e.g. "Deactivate Priya Sharma"), `tooltip` ("Deactivate" / "Activate"), `disabled`, `onChange(next)`.
- Track `border-strong` off, `primary` on; 12px `surface` knob. Hover dims slightly; focus is a 2px `focus-ring` outline with a 2px gap.
