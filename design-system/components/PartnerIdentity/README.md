# PartnerIdentity

A partner shown as their business: logo (or a store placeholder), business name, "Partner since …" and status.

- **You supply** `name`, `since`, `logo` or `initials`, `size` and `status`. On the website a partner is shown this way everywhere, including Shared Safari comments; the header's account button shows the logo (SiteHeader `user.logo`). Source: PK-P8, PK-C2.
