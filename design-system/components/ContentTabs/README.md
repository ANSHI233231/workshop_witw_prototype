# ContentTabs

A bordered panel with underline tabs and the open tab's content.

- **You supply** `tabs` and either `panels` (one node per tab) or a function child that gets the open index.
- Package page: Overview · Itinerary · Inclusions · Getting there · FAQs. Park page: Overview · Packages · Shared Safaris.
- The current tab is `primary` with a 2px underline. Source: PK-W4, PK-W8.
