# ItineraryDay

One day of a package's itinerary: a green "Day 1" pill, the day title, the description, its details and an optional day image.

- **You supply** `n`, `title`, `text`, `details` as [label, value] (Start and end, Hotel, Meals, Activity, Accommodation, Note — only those filled), `image`, and a GallerySlider as `children` when the day has a gallery.
- Put the days inside ContentTabs' Itinerary tab. Source: PK-W4.
