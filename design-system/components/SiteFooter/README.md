# SiteFooter

The WITW website footer: the grass-and-animals strip, four columns (About Us, Policy, Useful Links, Contact Info) and a bar with the wordmark, the developer and the copyright.

Use it at the bottom of every website page.

- **You supply** `grass` (Images group, `footer-grass.png`) and `wordmark` (Logos group). The text defaults to WITW's own copy; pass `about`, `policy`, `links`, `address`, `email`, `instagram`, `developer` or `copyright` to change it.
- Links given as plain strings are shown but do nothing (as on the boards); give `{ label, href }` for a real link. Hovered links turn `accent-1`.
- White text on `primary`; headings 16px semibold, text 14/22.
- Source: every Web board.
