# SearchInput

The search box in a table's filter bar, with a search icon inside on the left.

- Provide: `placeholder` (as the app: "Search by name, mobile, email…"), `value`, `width` (`md` → `field-width-md` by default), `invalid`, `disabled`, `onChange`.
- `surface`, 1px `border-strong`, `radius-md`, height `control-height`; icon and placeholder `text-subtle`. Hover border `text-subtle`; focus border `primary` + `focus-ring`; error border `danger` with a faint red ring.
