# ProfileLink

A person's name that opens their profile: bold, in the surrounding colour, underlined on hover.

- Provide: `name` or children, `href`.
- A user's name opens their User Profile; a partner's business name opens the Partner Profile. Use it for hosts on safari cards and the safari page, comment and reply authors, the Interested list, "Operated by" on the package page, and the other person in a conversation.
- Source: U3, U5, P2, W1, W3.
