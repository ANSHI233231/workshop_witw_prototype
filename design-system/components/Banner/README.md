# Banner

A one-line message across a page or form: info, success, warning or danger.

- **You supply** `tone` and the text; `icon` adds Lucide info. Use it for standing facts ("v1 stays live on the website until this version is approved.", "View only…", a rejection reason), not for action results (those are Toast).
- Its border is the tone's dot colour. Source: PK-P5, PK-P8, PK-C pages.
