# Banner

A full-width notice line inside a page or editor: what is going on and what to do next.

- Provide: `tone` (`info` default | `success` | `warning` | `danger`) and the text.
- Colours `badge-<tone>-bg` and `-text`, `radius-md`, 12px 14px padding. Reasons for a rejection go in a `danger` banner above the editor.
