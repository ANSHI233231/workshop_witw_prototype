# SectionTabs

Underline tabs that switch a section of the package, park, Wishlist, Partner Profile, User Profile and Edit Profile pages.

- Provide: `tabs` (strings or `{label,count}`), `active`, `onChange`.
- Uses `.nt-tabs`: 46px tabs on a `border` line; the current tab is `primary`, semibold, with a 2px `primary` underline; hover underlines in `border-strong`. Counts show after the label (not on the first tab). Scrolls sideways under 900px rather than wrapping.
