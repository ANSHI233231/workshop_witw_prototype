# PortalNotification

A row of the Partner portal's Notifications page: initials, the sentence with the name in bold, the time, and an orange dot while unread.

- **You supply** `initials`, `before` / `who` / `after`, `time`, `unread` and `onOpen` (a quote request opens Quote Requests). Partners are notified of new quote requests and of Super Admin messages only. Source: PK-P8.
