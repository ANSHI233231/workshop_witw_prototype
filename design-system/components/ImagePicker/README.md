# ImagePicker

Choose an image: a preview (or placeholder), Choose logo / Choose image, Remove, and a line of rules.

- **You supply** `label`, `variant` (`logo` 64px square; `image` 160px wide), `image`, `accept` and `helper` ("JPG, JPEG, PNG or WEBP, up to 1 MB." for a logo; "JPG, JPEG or PNG, up to 250 KB." for package and banner images).
- Source: PK-W1, PK-P5.
