# PhotoUpload

Edit Profile's Profile Photo and Cover Photo tabs: the preview, Upload / Change photo, Remove photo and the file rule.

- Provide: `kind` (`profile` | `cover`); optional `image`, `onRemove`, `id`, `accept`, `helper`, `error`.
- Rules: JPG, JPEG or PNG; profile up to 250 KB, cover up to 500 KB. Without a photo the placeholder shows.
