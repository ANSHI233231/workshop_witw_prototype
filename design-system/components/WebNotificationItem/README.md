# WebNotificationItem

One notification on the website's Notifications page: initials, the sentence, a tag and the time, with a dot while unread.

- **You supply** `initials`, the sentence as `children` (names and the safari in bold), `tag` (`success` "Shared Safari", `info` "Account"), `time` and `unread`.
- Unread rows sit on `primary-soft` with a `primary` dot.
- Put the rows in a card under Tabs (All, Unread, Shared Safari, Account).
- Source: Web-Notifications. The Console's bell keeps NotificationItem.
