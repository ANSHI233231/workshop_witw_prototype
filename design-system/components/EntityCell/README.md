# EntityCell

A table cell naming a package or partner: an optional thumbnail or initials square, the name in bold, a grey second line, and a red reason line.

- **You supply** `title`, `sub` (partner, package link, phone), `reason` (rejection), and `image` (56 × 40) or `initials`. Source: PK-P4, PK-P7, PK-C2, PK-C3, PK-C4.
