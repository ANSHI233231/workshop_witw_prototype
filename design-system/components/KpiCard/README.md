# KpiCard

A dashboard number card: label, icon tile, big number and a short meta line.

- Provide: `label` ("Users"), `icon`, `value`, `meta` ("3 active").
- Label and meta `caption` in `text-muted`; value `kpi`; icon in a 32px `primary-soft` tile, `radius-md`. Four per row on desktop (`.st-kpi-row`).
