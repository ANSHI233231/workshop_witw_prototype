# QuoteForm

Request a quote on the package page, beside the sections (stacked under them on phones).

- Default: travellers, start date, notes with a 0 / 1,000 counter, and Request a quote.
- `viewer: 'guest'` shows "Log in to send a quote request to this operator." with Login; `viewer: 'partner'` says partners can’t send quote requests and links to the Partner portal (`portalHref`).
- Optional `loginHref`, `onSend`.
