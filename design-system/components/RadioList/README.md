# RadioList

A list of choices, one per line, with an optional grey hint under each.

- **You supply** `name`, `label` (read by screen readers), `options` and the chosen `value`.
- Change status uses hints ("Shown to everyone"); Flag this comment's reasons use `tight` rows.
- Put it inside a Dialog; the radios are tinted `primary`.
- Source: W6 Change status, W8 Flag a comment.
