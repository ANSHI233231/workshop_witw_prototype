# AccountMenu

The account menu under the header's account button.

- Default items: My Profile, Wishlist, Messages (with the unread count), My Shared Safaris, My Quote Requests, Log out. Provide `user` `{name, initials, photo}`; optional `unread`, `current`, or your own `items` `[{label, icon, href, count, divider}]`.
- Partners have no Wishlist or Messages; pass their own `items`.
