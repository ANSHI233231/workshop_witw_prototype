# DetailList

Label–value pairs for a record's details in the Console.

- **You supply** `items` as [label, value] pairs; an empty value shows "–". `columns: 2` puts two pairs on a line (safari details); the default is one pair a line (park details). `title` adds a small uppercase heading.
- Put it inside a Card.
- Labels are `text-muted`, values `text`, 14/20.
- Source: C3 Shared Safari detail, C6 Park detail.
