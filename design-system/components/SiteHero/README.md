# SiteHero

The dark title band under the website header: an uppercase display title and an optional line under it.

Use it once per website page, right under SiteHeader, for the page's own name ("Join or Organize a Shared Safari", "Shared Safari", "Notifications").

- **You supply** `title` and, optionally, `text`.
- The band is 112px tall, the hero photo (Images group, `hero.jpg`) over `hero-ground`; the title is 26px bold in `font-display` (Devator Exp, else Roboto), uppercase with 0.05em tracking; the line is 14px at 85% white.
- Source: W1, W3, Web-Notifications.
