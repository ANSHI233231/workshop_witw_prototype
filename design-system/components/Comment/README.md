# Comment

One comment in a safari's Discussion, with the replies under it indented behind a grey line.

- **You supply** `initials`, `name`, `time` ("2 days ago"), `text` and `replies`. Mark the safari's host with `host` — the name then reads "Riya Sharma (Host)".
- Every comment has a Flag button (`onFlag` opens Flag this comment); hide it on your own comments with `canFlag: false`.
- Put comments straight inside a SitePanel; the first has no line above it.
- Source: W3, W8.
